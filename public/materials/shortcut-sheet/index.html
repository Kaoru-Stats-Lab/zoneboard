Broadcast shortcut sheet

Print or save as PDF (Ctrl/Cmd+P). Keep it beside your keyboard during a show.

Broadcast mode (B) hides the tools. You move pieces with the keyboard. Try the keys here before you go live — the same keys work during the stream. There is no first-run overlay on the pitch. This panel and the public guide are the manual.

Select pieces

KeysAction
ClickSelect one piece
Ctrl/Cmd+ClickAdd or remove
Shift+ClickAdd (keep rest)
Drag empty grassBox select
Alt+1 / Alt+2All home / all away
Ctrl/Cmd+ASelect all visible
EscClear selection

Move the selection

KeysAction
Drag a selected pieceMove the whole selection
Arrow / Shift+ArrowNudge (fine / coarse)
RFacing +45° only
Q / ERotate shape at centre
- / =Closer / wider
Shift+H / Shift+VFlip H / flip V
Ctrl/Cmd+DDuplicate (copies selected)
Ctrl/Cmd+Shift+ArrowAlign to edge or axis
Alt+Shift+ArrowEven spacing (H / V)
DeleteRemove selected pieces

Draw before the stream

KeysAction
PassBall path (dashed)
Run / DribbleRun or dribble
PenFreehand line
LinkPiece link (follows)
Shift+Pen dragStraight line A to B
Zone + ShiftNear-circular zone

Before and during the stream

KeysAction
BToggle broadcast mode
[ ] or PageUp/PageDownSwitch scenes
Duplicate (Scenes or bottom-right)Copy scene, try a move
? or F1How-to (not live)

Updates

This page lists changes that are already live. It is not a roadmap. Upcoming work stays elsewhere. Feedback still goes through Contact or the in-app form.

Shipped changes only, in past tense. Upcoming work stays off this page.

Updated 2026-08-31

Shipped timeline

  1. 2026-08-31 · Improve

    Drawing tools return to Select after each action

    Pass, run, dribble, pen, zone, text, and link now switch back to Select when you finish a stroke or confirm a link chain. Home and away pieces still return to Select after placement; ball stays active for dragging. The tool rail pins Select, shows the current tool, and highlights link mode while you chain pieces.

  2. 2026-08-31 · Improve

    Portrait pitch viewport presets and thumbnails

    On portrait soccer boards, scene camera presets now zoom to the correct goal, corner, and touchline areas. Thumbnails use a vertical pitch with a finder overlay. Landscape boards and other sports are unchanged.

  3. 2026-08-31 · Feature

    Portrait pitch and Pitch View picker

    Soccer boards can use a portrait pitch with goals top and bottom — separate data from landscape, not a coordinate map. The Match tab Pitch View row is five icons for landscape and portrait full and half. Switching landscape ↔ portrait resets every scene to an empty pitch with a centred ball. Match banner stays off in portrait.

  4. 2026-08-31 · Feature

    Optional name pills on the pitch

    Turn starter name pills on or off in the Match tab. Bench players always show a name chip so your XI line stays readable when names are off. New boards default to numbers only; older saves keep names on.

  5. 2026-08-28 · Feature

    Pan the pitch with Space+drag

    Hold Space and drag to move the camera on a zoomed pitch. Release Space to place pieces again. The shortcut sheet lists Space+drag.

  6. 2026-08-28 · Feature

    Duplicate scenes, review notes, and a shortcut sheet

    Duplicate a scene from the Scenes drawer to try a pattern and switch back. Each scene can carry a short review note. A printable shortcut sheet lives under Materials and in the how-to footer.

  7. 2026-08-28 · Improve

    Clearer PNG export and swap-end behaviour

    Pitch-only PNG export no longer draws chrome around the board. When you swap ends, scenes rotate 180° instead of mirroring. Broadcast framing keeps a 16:9 island with black matte on wider windows.

  8. 2026-08-27 · Feature

    Link tool, kit colours, and Japanese board menus

    The Link tool draws ink paths between pieces. Kit colours accept full HEX values. Board chrome can follow Japanese when you choose 日本語 in Settings; landing and reading pages stay English. New boards can open on an in-progress tactical moment instead of a blank line-up.

  9. 2026-08-27 · Feature

    Free and Pro plan foundation

    Pricing pages now describe Free and Pro tiers. Pro is a local library entitlement on your device — not a cloud account. Checkout is not live yet; the board stays usable without signing in.

  10. 2026-08-26 · Improve

    Clearer PNG post framing labels

    Post framing “full field” means the camera zooms out. Portrait formats still crop the pitch. Use 16:9 or Pitch ratio when you need the whole field in the frame.

  11. 2026-08-26 · Feature

    Optional PNG credit, share blurb, and OGP image

    Settings can add a small zoneboard.app line under a social PNG (off by default, never on live capture). Materials includes a stream description blurb. Public pages ship full Open Graph and Twitter cards.

  12. 2026-08-26 · Feature

    Live match undo and PK goal labels

    You can undo or delete a recent goal, card, or sub from the live controls when a name is mistyped. Penalty goals can be tagged so the match banner shows PK before the scorer.

  13. 2026-08-26 · Feature

    Broadcast sub marks and PK shootout strip

    OUT, IN, and injured states show on pieces. A penalty shootout strip lives on the match banner for viewers. Closing the PK input keeps results on the banner. Sub caps are not counted in the product.

How we write this

Past tense only. If a change would not change how you use the board or the site, it does not belong here.

The source of truth is the changelog module in the repo. Editors run the site page build after updating it.

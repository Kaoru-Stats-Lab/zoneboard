Updates

This page lists changes that are already live. It is not a roadmap. Upcoming work stays elsewhere. Feedback still goes through Contact or the in-app form.

Shipped changes only, in past tense. Upcoming work stays off this page.

Updated 2026-08-26

Shipped timeline

  1. 2026-08-26 · Improve

    Clearer PNG post framing labels

    Post framing “full field” means the camera zooms out. Portrait formats still crop the pitch. Use 16:9 or Pitch ratio when you need the whole field in the frame.

  2. 2026-08-26 · Feature

    Optional PNG credit, share blurb, and OGP image

    Settings can add a small zoneboard.app line under a social PNG (off by default, never on live capture). Materials includes a stream description blurb. Public pages ship full Open Graph and Twitter cards.

  3. 2026-08-26 · Feature

    Live match undo and PK goal labels

    You can undo or delete a recent goal, card, or sub from the live controls when a name is mistyped. Penalty goals can be tagged so the match banner shows PK before the scorer.

  4. 2026-08-26 · Feature

    Broadcast sub marks and PK shootout strip

    OUT, IN, and injured states show on pieces. A penalty shootout strip lives on the match banner for viewers. Closing the PK input keeps results on the banner. Sub caps are not counted in the product.

How we write this

Past tense only. If a change would not change how you use the board or the site, it does not belong here.

The source of truth is the changelog module in the repo. Editors run the site page build after updating it.

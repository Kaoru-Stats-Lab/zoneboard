## 2. ミニ俯瞰（ゴール選択）— W09 差分

**目的:** 画像に映っているゴールを、Canonical pitch のどのゴール口として扱うかを選ぶ。  
**目的でない:** 画面の左／右、攻撃左右を選ぶこと。

### Must

- ユーザー向け可視ラベルに **「左」「右」「Left」「Right」を出さない**（ボタン上・ミニ図旁の短文）。  
- コピーは **「映っているゴールを選ぶ」** / EN **「Select the goal you can see」** のみ。  
- 操作は俯瞰図上の **ゴール口（◎）クリック**。  
- 選択中は該当ゴール口をハイライト（塗り／枠）。説明文で L/R を補わない。

### 内部

- 状態は引き続き `calibGoalSide: "x0" | "x1"`。  
- `aria-label` / `title` も L/R を避け、必要なら **"Goal nearer this end of the diagram"** のように図上の位置で記述。実装では **図の両端ゴールを「この端のゴール」** と呼び、Canonical 対応はコメントとコードのみ。

### 罠（禁止）

```text
[ Left goal ]     [ Right goal ]   ← 禁止
```

## 5. 下部リスト — 操作モデル（本丸）

### 5.1 役割

下部は **選択肢カタログではない**。  

> 画像上の①〜④が何を意味するかを **確認**し、必要なときだけ **変更**するコントロール。

### 5.2 既定表示（Must）

各行は次の構造にする（ネイティブ `<select>` **禁止**）:

```text
①  ペナルティエリア角     [変更]
②  ペナルティエリア角     [変更]
③  ペナルティアーク       [変更]
④  ペナルティスポット     [変更]
```

- **主ラベルは常時可視のテキスト**（競技用語）。select の閉じた表示値に頼らない。  
- 「変更」はコンパクト。押下で **候補パネル**（popover / bottom sheet）を開く。  
- パネル既定: 文脈おすすめ **6〜8**。  
- 「すべてのポイント」で残りを追加表示（折りたたみ）。**OS ネイティブの全画面 option リストにしない。**

### 5.3 同名の区別（Recognition）

同じ表示名（例: ペナルティエリア角×2）を許す。  
`field top / field bot` に戻して区別してはならない。

**区別手段（Must · どちらか必須、併用可）:**

1. **ミニ俯瞰ピン:** フォーカス行／フォーカスハンドルに対応する Landmark を俯瞰図上に点で示す。  
2. **フルラベル（subtitle）:** ピッチ相対のみ — `ゴールライン側` / `ボックス奥（フィールド側）`。画面の上下左右語（top/bot/TL）は禁止。

### 5.4 認知フロー（完成形）

```text
画像を見る
→ 映っているゴールを俯瞰で選ぶ（L/R語なし）
→ 画角プリセット
→ ①–④が出る
→ 下部で意味を確認（読んで覚える必要なし）
→ 交点へドラッグ
→ ピッチを取り込む
→ コマ配置
```

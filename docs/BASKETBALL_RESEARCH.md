## 0. 一言で

日本バスケは **FIBA コート＋NBA 由来の語彙**（エルボー、ウイング、5アウト）。戦術説明の大半は **ハーフコート**。既存アプリはプレーブック／モバイル寄りで、**OBS 配信前提の軽量 Web** は手薄。

### コート規格メモ（Bリーグ＝FIBA）

| | 〜2009 FIBA（記憶の「昔」） | **現行 FIBA / JBA / Bリーグ** | NBA |
|--|---------------------------|------------------------------|-----|
| 制限区域（3秒） | **台形** | **長方形** 5.8×4.9 m（2010〜。日本は2013頃完全移行） | 長方形（以前から） |
| 3P | 弧がエンド近くまで続く印象の旧仕様（6.25 m 時代） | **弧 6.75 m ＋コーナー直線**（サイドから 0.90 m。エンドまで弧だけではない） | 弧 7.24 m、コーナーは短い |
| コート | 28×15 m | **同じ 28×15 m** | やや大きい |
| リング／ボード | — | 俯瞰記号として描画（ボード幅 1.80 m、リング φ0.45 m） | 同左 |

配信者が見る **Bリーグは FIBA**。台形ペイントは現行ではない（呼び名の名残だけ残る）。

## 1. 合意（3ソース）

| 項目 | 判断 |
|------|------|
| 規格 | **FIBA / JBA**（NBA 専用 UI はやらない） |
| 既定ビュー | **ハーフコート**が実質 Must |
| 人数 | 5人固定 |
| 補助線 Must | ペイント強調、3P強調、スポット（トップ・ウイング・コーナー・エルボー） |
| 補助線 Should | ミドルライン（ストロング／ヘルプ）、スロット線、シェル等 |
| 線種 | パス／ランに加え **スクリーン（T字）** が欲しい（Should〜Must） |
| コート色 | 白 or 木目。**緑は厳禁** |
| やらない | 選手DB、スコア／クロック、サッカーUI流用 |

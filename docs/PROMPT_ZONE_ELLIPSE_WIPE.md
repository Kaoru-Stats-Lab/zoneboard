# 実装プロンプト: ゾーンを楕円に / トーク用「図を消す」

ZoneBoard（`C:\asl_dev\zoneboard`）の作業。日本語でコミットメッセージと UI 文言を書く。LP コピーは触らない。重いアニメ・GIF・消しゴムブラシはやらない。

完了条件: `npx tsc --noEmit` が通る。ブラウザでゾーン描画・ヒット・Undo・図を消す・駒が残る、を確認する。

---

## 背景（なぜ）

サッカー解説・振り返りでよく見る操作は次の2つ。

1. **スペースを◯（楕円）で囲む**（ポケット、空き、ハーフスペース）。いまのゾーンツールは矩形で、語彙が違う。
2. **今書いた線・◯だけ消す**（駒は残す）。白板の「拭く」。描いて、話して、消して、次。

Ctrl+Z（Undo）は残す。図を消すは Undo の代替ではなく、トーク用の別ボタン。Undo は「直前の操作」全般（駒移動も含む）。図を消すは「描画オブジェクトだけ」を狙う。

---

## 1. ゾーンを楕円にする

### 決めてよい実装判断

**既定: ゾーンツールは楕円のみ。矩形ツールは増やさない。**

理由: トークで欲しいのは「空き」の◯。ツールを2つにするとレールが太る。データは既に AABB（`x, y, w, h`）なので、その矩形に内接する楕円を描けばスキーマ変更は不要。既存ボードの四角ゾーンは楕円に見えるようになる（許容。マイグレーション不要）。

Shift で正円に拘束する、はあってもよい（任意）。Shift で矩形に戻す、は不要。

### 触る場所

- 描画: `src/canvas/drawBoard.ts` の `obj.type === "zone"`（いま `fillRect` / `strokeRect`）
- ドラッグプレビュー: 同ファイルのゾーンプレビュー（矩形シード枠も楕円に）
- PNG: `drawBoard` 経由なら追加パスを作らない
- ヒット: `hitTestObject` の zone 分岐。AABB 内点ではなく **楕円の内部**（中心からの正規化距離 ≤ 1）。選択しやすくするためスロップは線ヒットと同程度でよい
- 作成: `src/components/BoardCanvas.tsx` の zone ドラッグ。保存データ形は変えない
- `src/hooks/useAppState.ts` の zone 追加

プレビューと確定描画で形が違わないこと。

### やらない

- ゾーンツールを2つに分ける
- `shape: "rect" | "ellipse"` を必須にしない（楕円のみならフィールド追加しない）
- 自由変形の楕円（回転）は不要。軸はピッチ軸に平行

## 2. トーク用「図を消す」

### 振る舞い

新しい関数（名前は `wipeDrawing` など）:

1. **描画オブジェクトが選択中**（`selectedObjectId`）→ それだけ消す。駒・ボールは触らない。
2. **描画が選択されていない** → 現在局面の `objects` の **末尾（最後に描いたもの）** を1つ消す。
3. 消す対象が無いときは no-op（ボタン disabled）。
4. **駒が選択されていても、このボタンは駒を消さない。** 最後の描画を消す（選択中が描画ならその描画）。
5. この操作は既存の history に載せる → **Ctrl+Z で戻る。**

既存のまま残すもの:

- **Ctrl+Z / Cmd+Z = `undo()`**（駒移動・描画・消し、すべて）
- **Ctrl+Shift+Z / Cmd+Shift+Z / Ctrl+Y = redo**
- **Delete / Backspace + 選択中** = いまの `deleteSelected()`（駒も消せる）
- 設定の「描画だけ全消去」=`clearDrawings`（確認ダイアログつき）。レールには出さない

### ショートカット（推奨）

- `Z` 単体はゾーンツールのまま（`Editor.tsx`）。**Ctrl+Z を奪わない**（いま通り Ctrl+Z を先に見る）。
- 図を消す専用キーは必須にしない。ボタンが主。
- 入れるなら **Ctrl+Backspace**（Mac は Cmd+Backspace）を `wipeDrawing` に。入力フォーカス中は無視。素の Backspace は選択削除のまま（駒を消しうるので、トーク用ボタンと混ぜない）。

### UI

Undo の **隣**（右、または Undo の直前でも可。並びは `図を消す` → `戻す` か `戻す` → `図を消す`。トークでは消すが先でもよい。どちらでも一貫させればよい）。

- 編集: `src/components/ToolRail.tsx`（undo ボタンの隣）
- 配信: `src/components/BroadcastToolMenu.tsx` のポップ内、undo の隣。配信中もトークで使う。

ラベル（短く）:

- ja: `図を消す`（title に「最後の線・ゾーン。駒は残る。Ctrl+Z で戻す」）
- en: `Wipe`（title: `Remove last drawing or the selected one. Pieces stay. Undo with Ctrl+Z.`）

`src/i18n/messages.ts` の ja / en 両方。キー例: `wipeDrawing` / `wipeDrawingHint`。

オブジェクトが0のとき disabled。

### やらない

- ストロークをなぞって消す消しゴム
- 図を消すで駒・ボール・局面全体を消す
- Undo を「図だけ」に変える
- 設定の全消去をレールに出す

## 3. 品質

- 芝ピッチ（白線）でもゾーンの塗り・線が読める。既存 `zoneColorsForBoard` を使う
- 配信モードでツールレールは隠れるが、BroadcastToolMenu から図を消せる
- タッチ: ボタンは指で押せるサイズ（既存 undo に合わせる）
- 履歴: 図を消す → Ctrl+Z で復元。その後 Ctrl+Y で再消し

## 4. 確認手順

1. ゾーンツールでドラッグ → 楕円。プレビューと確定が同じ。
2. 楕円の内側クリックで選択、外側（外接矩形の四隅で楕円の外）は選択しない。
3. パスを引き、ゾーンを描き、駒を動かす。
4. 「図を消す」→ 最後のゾーンが消える。駒は残る。
5. Ctrl+Z → ゾーンが戻る。
6. ゾーンを選択して「図を消す」→ そのゾーンだけ消える（後から書いた線が残る）。
7. 駒を選択した状態で「図を消す」→ 駒は消えず、最後の描画が消える。
8. Delete で選択駒が消える（従来）。Ctrl+Z で駒も戻る。
9. 配信モードのメニューからも図を消せる。
10. PNG 書き出しでも楕円。

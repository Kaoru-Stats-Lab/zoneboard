## 五役の問い（必ず全部に答える）

### CPO

- 8秒で「ボードの名前」か「ゾーンの会社」か、どちらに読めるか
- 配信キャプチャで、運営と配信者のどちらの顔が残るか
- ZONE を太らせる提案は、クレド「ZoneBoard はボードだけ」と矛盾しないか

### シニア UX/UI

- ロックアップは H1・CTA・第一マーカーと信号が競合していないか
- chrome（〜48px）で識別子として足りるか。ディスプレイ書体で主張しすぎないか
- LP とボードで同じ部屋に見えるか（地・字・マーク）

### ウェブ

- UI が生テキスト、OG/印刷がアウトライン、という分担は崩れていないか
- 16px / 24px / 32px / OG で形が持つか。ネスト SVG や字切れはないか
- 明地・キット色・芝の上で、使ってはいけない組み合わせが混ざっていないか

### 認知

- CamelCase 一語は Zone + Board として束ねられるか。ウェイト分割したら遅れるか
- ポップアウトは第一マーカー一つか。字の Z/B が第二の金になっていないか
- 狭いトップバーで単語形状が壊れていないか（広い字間、折り返し）

### HCI

- トップバーのロックアップはホームリンクとして足りる当たりか（語を消すと 24px アイコンだけになる）
- ファビコンとロックアップと口頭名（ZoneBoard）は同じものか、第三の「ZB」が要るか
- 斜体やシアーは「運動ブランド」へカテゴリを間違えないか

Nielsen は噛んだ番号だけ書く（一貫性、システムと世界の一致、認識 vs 再生、美的で最小）。

# バスケットボール — リサーチ・ブリーフ（Gemini / ChatGPT / Claude 用）

**更新:** 2026-07-04  
**粒度:** [`PRODUCT_NOTE.md`](PRODUCT_NOTE.md)（サッカー）・[`FUTSAL_BEACH_RESEARCH.md`](FUTSAL_BEACH_RESEARCH.md) と同型  
**使い方:** §3 のプロンプトを順に貼る → 回答を末尾「結果メモ」に要約転記 → 実装ギャップを [`BACKLOG.md`](BACKLOG.md) へ  
**プロダクト前提（必ずプロンプトに含める）:**

- ZoneBoard = ブラウザの俯瞰戦術ボード。**配信でピッチ最大化**、ユーザロゴ透かし、登録不要・ローカル保存  
- **持たない:** 選手 DB、スコア／タイマー UI、運営ロゴ、動画解析  
- スコア・ショットクロックは **OBS 側**  
- **現状実装:** FIBA 系コート線（白面・黒線）、5人＋ベンチ、バスケ球、パス/ラン/ドリブル流用。**補助線トグルなし**（サッカー5レーンのようなオーバーレイは未実装）  
- v1 UI 言語は **ja / en**。次言語は別調査（es 等）

## 1. 調べる対象

### 1-1. 国内（ja 優先・最初にやる）

| 優先 | 対象 |
|------|------|
| Must | 日本（Bリーグ解説、高校・大学バスケ、部活監督、YouTube 戦術解説） |
| Must | 日本の指導語彙（FIBA 準拠か NBA 語彙の混在か） |

### 1-2. 海外（強豪・コンテンツ大国）

| 優先 | 国・圏 | なぜ |
|------|--------|------|
| Must | **米国** | NBA・指導コンテンツ・配信文化の震源。en |
| Must | **スペイン** | 欧州クラブ戦術・育成。es |
| Should | **セルビア／リトアニア等** | 指導文化が厚いが en で足りるか |
| Should | **フランス・ドイツ** | ユーロリーグ視聴・指導 |
| Later | 中国・フィリピン等 | 市場は大きいが v1 後 |

**規格の切り方:** FIBA コート（ZoneBoard 現状）と NBA コート（寸法差）を**混同しない**。日本は FIBA。配信者が NBA 図を欲しがるかは要確認。

## 2. 調べる粒度（MECE）

| # | 観点 | 聞きたいこと |
|---|------|--------------|
| A | **指導・競技の厚み** | ライセンス、クラブ／学校、公式教材 |
| B | **戦術ボードの悩み** | 代用品（ホワイトボード、パワポ、アプリ名）と不満（コート比、線、保存、広告、配信で小さい） |
| C | **利用ツール** | TacticalPad、Hoop Strategist、専用バスケボード、TACTICALista 等 |
| D | **補助線・グリッド（最重要）** | ペイント強調、スリーポイント弧、弱いサイド、ヘルプライン、シェルDF、トランジション帯など。**Must / Should / 不要**を分ける。現地語 |
| E | **配信者** | YouTube / Twitch で戦術図を出すか。ハーフコート図が多いかフルか。OBS 運用 |
| F | **人数・フォーメ** | 5人固定で足りるか。ゾーン／マンの図示需要 |
| G | **ZoneBoard が刺さる点** | 配信最大化、ユーザロゴ、登録不要、正しい FIBA 線 |
| H | **やらないこと** | スコアクロック内蔵、選手スタッツ DB、サッカー5レーン流用など |

**出力形式（強制）:**

1. 国内サマリ表（A–H）  
2. 海外（米・西）サマリ表  
3. **補助線カタログ**（名前・用途・Must/Should/不要・既定ON推奨か）  
4. ZoneBoard への含意（Must / Should / Later / やらない）  
5. 現地コーチ・配信者に聞く問い（最大8つ）  
推測は推測と明記。日本語で回答。

### 3-1. 日本（最初）


## 結果メモ（2026-07-04）— ChatGPT / Claude / Gemini 統合

### 合意

- **ハーフコート**が説明の主戦場（既定ビューに）
- **FIBA / JBA**、白面。緑コート禁止
- Must 補助線: **ペイント・3P・スポット（トップ／ウイング／コーナー／エルボー）**
- Should: ミドルライン、スロット、シェル、テンプレ、スクリーンT字、木目
- やらない: 選手DB、スコア、サッカーUI

### 実装反映

- ハーフ／フル切替（バスケ既定ハーフ）
- トグル: ペイント強調、3P強調、スポット、ミドルライン、スロット線

### 未実装（Should）

- スクリーン T字線種、5-Out/Horns テンプレ、木目コート、シェル

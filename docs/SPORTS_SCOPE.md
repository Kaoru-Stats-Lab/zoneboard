# スポーツ市場 MECE と ZoneBoard 対象競技

**更新:** 2026-07-04  
**入力:** Gemini による巨大市場 × 戦術重要度 × 2D ボード適性の整理  
**結論:** **v1 = サッカー · バスケ · バレー**。**v1.1 = フットサル · ビーチサッカー（サッカーとは別競技ページ）**

---

## 1. MECE マップ（戦術・ポジションが重要な巨大市場）

軸: **空間の性質 × ゲーム目的**。「2D ボードで図解する価値」を含む。

| # | カテゴリ | 代表 | 市場 | 戦術重要度 | 2Dボード適性 |
|---|----------|------|------|------------|--------------|
| **①** | **侵入・ゴール型** | サッカー、バスケ、アメフト、ラグビー、アイスホッケー、ハンドボール | 最大 | 極めて高い | **最高** |
| **②** | **ネット・境界型** | バレー、テニス、バドミントン、卓球 | 大 | 高い（特にバレー配置） | **高い** |
| **③** | **ターゲット・ベース型** | 野球、クリケット、カーリング | 大〜中 | 中〜高 | 中（流動動線は少ない） |
| **④** | **コース・集団レース型** | F1、自転車ロード | 巨大 | 極めて高い | **低い**（ルート／データ主体） |
| **⑤** | **バーチャル・アリーナ型** | eSports（MOBA / タクティカル FPS） | 急成長 | 極めて高い | **最高**（マップ差し替えで転用可） |

球技に限る必要はない。ただし v1 は **長方形コート・中密度の駒・配信文化** で切る。

## 2. v1 選定基準

| 基準 | 内容 | v1 への帰結 |
|------|------|-------------|
| **UI 共通性** | 長方形コート、自他陣、センター／制限区域の線 | サカ／バス／バレで描画ロジックを共有 |
| **駒密度** | 配信で ≥80% ピッチでも駒が潰えない | 5〜11人／チームが上限感。ラグビー15人×2は Later |
| **配信者文化** | 俯瞰ボードで LIVE／動画する習慣 | サカ・バスケ・バレーが定着。バスケ／バレはサッカー専用ツールから漏れている |

### v1 で扱わない（Later / 別系統）

| 競技・領域 | 理由 |
|------------|------|
| ラグビー・アメフト | 駒密度・ヤード／スクラム表現が重い |
| アイスホッケー・ハンドボール | ①だが v1 の3競技で十分。需要確認後 |
| テニス・バドミントン・卓球 | 個人ネット型。配置需要はバレーより弱い |
| 野球・クリケット | 扇形・対峙型。キャンバス前提が違う |
| F1・自転車 | マップ／データ主体。ボードの仕事ではない |
| **eSports** | 将来の伏兵。コート画像をマップ PNG に差し替えるだけで転用可（v2+） |

## 2b. 入力デバイス（PC / タブレット / 大型タッチ）

物理マグネットボードと同様、**指で駒を動かす**需要がある（配信ブースのタブレット、壁掛けタッチパネル）。

| 入力 | v1 | 備考 |
|------|-----|------|
| **マウス + ホットキー** | 主戦場 | 使いこなし層の加速装置 |
| **タッチ（タブレット・大型パネル）** | **必須級** | ホットキーは使えない。ポインタ操作だけで完結 |
| タッチ操作 | 1本指ドラッグ（駒・ボール・描画）、**ピンチズーム**、**2本指パン**、当たり判定拡大 | Alt / 中ボタンに依存しない |

学習コスト指針どおり: タッチでも「駒を動かすだけ」で足りる。ホットキーは PC 限定の任意加速。

## 3. 競技別オーバーレイ（補助線）方針

| 競技 | v1 | Later |
|------|-----|--------|
| サッカー | **5レーン**（ハーフスペース）、ファイナルサード画角 | thirds 明示オーバーレイ |
| バスケ | コート線のみ（FIBA） | ペイント強調、弱いサイド等 |
| バレー | コート線のみ（アタックライン含む） | ローテ番号、ブロックゾーン |

バスケ／バレの「流行の補助線」は、配信者需要が固まってから。v1 は **線の正確さ＋全画面** を優先。

## 1. ジョブ

プリセット画角は **キャプチャの再現単位**。配信・記事・SNS で「CK のこの図」を毎回ホイール微調整させない。

サッカーライター／コーチ基準: その画角だけで **選手の動き（ラン・ショート・レストディフェンス）** が語れること。アングル（俯瞰／アイソメ）は問わない。**見える面積**が正本。

## 2. 失敗ログ

### 2a. 旧 `corner-*`（zoom 2.4 · 角寄り）

- コーナー弧のみ → **ゴール外** → CK を語れない

### 2b. 「ゴール入り」だけではまだ足りない（2026-08-25・参考図）

ゴール＋ペナだけでは解説不能。現場・教本が同じ面積を取っている。

**動きとして必須の語彙エリア**

1. キッカー／コーナー弧  
2. ショートオプション（タッチライン沿い）  
3. ゴール口・6ヤード・ペナ（ニア／ファー／ゾーン）  
4. ペナ外・D周辺（セカンドボール・シュート）  
5. **レストディフェンス（おおよそハーフウェイまで）**

「角のアップ」はホイール。プリセット名が CK なら上記まで。

## 3. 設計原則（正本）

1. **ランドマーク必須セット**で画角を定義（点ズーム禁止）
2. AABB → 中心・zoom（正方形カメラ制約あり: 幅1を満載するとほぼフルに近い）
3. Export「いまのズーム」＝プリセットと同じ Viewport
4. 制作会社の好みはホイール。プリセットは「最低限語れるフレーム」

### CK 角（`corner-*`）— 解説用

Must:

- コーナー旗／弧  
- ゴール口  
- ペナ全体（当該エンド）  
- ショートが置けるタッチ際  
- ペナ外〜おおよそ **x 方向にハーフウェイ付近**（レストDF）

### CK 配置（`ck-setup-*`）

左右どちらの角からでも読める **攻撃エンド俯瞰**。両タッチは切れにくいよう広め。角ボタンより「標準セットの全体」向き。

### 制約（ZB）

カメラは正規化座標で正方形。教本の「横長ハーフ図」をそのままは再現できない。同じ **必須面積**を正方形に内包する。

**外側の扱い（2026-08-25）:** ゴール裏・ピッチサイドは **規定余白のみ**（`CAPTURE_OUTSIDE_MARGIN`）。必須矩形の中心にカメラを置くと外側が膨らむ → ピン辺をゴールライン／タッチに合わせ、余りはピッチ内側へ。毎回同じ余白＝キャプチャのブランド再現。

実装: `viewportCoveringRect`（Scenes の CK プリセット）。局面画角: `scene.viewport`（`src/models/scene.ts` · `activeViewport`）。

# SNS 出力から逆算するボードの出し方

**更新:** 2026-07-04  
**指針:** キャプチャ → X / Threads / IG / Reddit に貼れることがゴール。配信ループの終点。

---

## 0. いちばん大事なズレ

| 文脈 | デバイス | 画角 |
|------|----------|------|
| **配信** | PC・OBS | **横ワイド**（16:9 モニタ） |
| **投稿** | スマホネイティブ（X / IG / Threads） | **縦寄り**（1:1 · 4:5 · 9:16） |

配信画面をそのままスクショして X/IG に貼ると、スマホでは小さく・余白だらけになる。  
**配信用レイアウトと投稿用 Output は別物**と割り切る。

| ステージ | ZoneBoard の答え |
|----------|------------------|
| 配信中 | 配信モード・横いっぱいのピッチ（OBS） |
| 投稿用 | **縦／正方形プリセットで書き出し**（レターボックス or ズーム局面） |

セットプレーや「一瞬の構造」は、配信では横で見せ、投稿では **ズームしたまま 4:5 / 1:1 / 9:16 で焼く**と映える。

---

## 1. プラットフォーム別の「勝ち画角」

| 媒体 | 推奨アスペクト | 目安解像度 | タイムラインでの見え方 |
|------|----------------|------------|------------------------|
| **X** | **16:9** または **1:1** | 1920×1080 / 1080×1080 | 横長は情報量、正方形はスマホで大きい |
| **Threads** | **1:1** または **4:5** | 1080×1080 / 1080×1350 | IG に近い。正方形が無難 |
| **Instagram Feed** | **1:1** または **4:5** | 同上 | 4:5 が画面占有最大。16:9 は小さい |
| **IG Story / Reels** | **9:16** | 1080×1920 | 上下に余白 or ズーム寄りの局面 |
| **Reddit** | **16:9** またはネイティブ | 1920×1080〜 | r/soccer 等は横長が読みやすい |

サッカーピッチ比（105:68 ≈ **1.54:1**）はどの SNS ネイティブ比とも一致しない。  
→ **キャンバスを SNS 比で切り、ボードを中央配置＋余白**が正解（レターボックス）。無理にピッチを歪めない。

---

## 2. 映えるボードの出し方（ディレクター判断）

### 必須に近い

| 要素 | 判断 |
|------|------|
| **UI を載せない** | Export はキャンバスのみ（現状どおり） |
| **高コントラスト** | 白地＋黒線＋色付き駒。配信キャプチャでも読める |
| **ロゴ焼き込み** | 拡散時の帰属。不透明度 30–50%、レイヤは線の下 |
| **文脈テキスト** | 単体投稿では「試合名・局面」がないと何の図か分からない → **キャプション焼き込み（任意）** |

### 使い分け

| 投稿の型 | 画角 | ボードの見せ方 |
|----------|------|----------------|
| **全体戦術・フォーメ** | 16:9 or ネイティブ | viewport = 全体 |
| **セットプレー・一瞬の構造** | 1:1 or 4:5 | **いまのズーム（CK 等）をそのまま Export**。プリセットはゴール等の必須ランドマーク入り（[`VIEWPORT_RESEARCH.md`](VIEWPORT_RESEARCH.md)） |
| **ファイナルサード（攻撃側 1/3）** | 1:1 or 4:5 | 投稿フォーカスで **FT左 / FT右**（配信の横全体とは別） |
| **ストーリーズ用フック** | 9:16 | ズーム寄り＋上下余白にキャプション |

### やらない

- ピッチを正方形に歪める
- SNS 用に駒を自動で巨大化（ユーザの pieceScale に任せる。映えたい人は「戦術（大）」）
- 自動ハッシュタグ生成・API 直投稿（v1 スコープ外。ファイルを渡すだけ）

## 3. Output 仕様（実装）

Export プリセット:

| ID | 用途 | サイズ |
|----|------|--------|
| `native` | Reddit・資料・汎用 | 長辺 1920・ピッチ比 |
| `x169` | X・Reddit | 1920×1080 |
| `square` | X / Threads / IG | 1080×1080 |
| `ig45` | IG / Threads 縦 | 1080×1350 |
| `story` | Story / Reels | 1080×1920 |

共通オプション:

- 透かし焼き込み ON/OFF
- **キャプション焼き込み** ON/OFF（`matchLabel` · 局面名。空なら出さない）
- **投稿の画角:** いまのズーム / 全体 / **ファイナルサード（左・右ゴール）**

余白色: `#f4f4f4`（白ピッチと区別しつつクリーン）

---

## 4. ユーザへの一言ガイド（LP / 設定に短く）

> 配信は横、投稿は縦。スマホ用は正方形か 4:5 で書き出す。セットプレーはズームしたまま。試合名を入れると単体でも伝わる。

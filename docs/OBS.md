# ZoneBoard × OBS 配信メモ

**更新:** 2026-07-04

## ボードの置き場所（アプリ側）

| モード | レイアウト | OBS 向け |
|--------|------------|----------|
| 編集 | 薄いヘッダ + キャンバス + 右ドロワー | キャプチャ範囲にドロワーが入りやすい |
| **配信モード**（`B`） | ドロワー強制クローズ。解除ボタンのみ端に残る | **推奨**。ピッチ面積 ≥80% 契約 |

配信時はブラウザを **配信モード**にしてからキャプチャする。

推奨ウィンドウサイズ: **1920×1080**（16:9）。ピッチは FIFA 推奨 **105×68**（≈1.544:1）なので、上下にサブ帯・タイトル分の余白が乗る。

## OBS の取り方

### A. ウィンドウキャプチャ（手軽）

1. ZoneBoard を通常ウィンドウで開く（最大化可）
2. 配信モード ON（`B`）
3. OBS → ソース → **ウィンドウキャプチャ** → ブラウザウィンドウを選択
4. 「クライアント領域」相当があれば ON（枠・タイトルバーを除外）

注意: 他タブや通知が写り込む。ブラウザ UI（タブバー）はウィンドウ次第で残る。

### B. ブラウザソース（URL 直読み・きれい）

1. `npm run build` 後に静的ホスト、または `npm run dev` の URL
2. OBS → ソース → **ブラウザ** → URL に  
   `http://localhost:5173/ja/board`（本番は `https://zoneboard.app/ja/board`）
3. 幅 1920 / 高さ 1080
4. カスタム CSS で余白を消す場合の例:

```css
body { margin: 0; background: #000; overflow: hidden; }
```

注意: ブラウザソースは **別プロファイル**のため、通常 Chrome の localStorage と共有されない。配信用に同じボードを使うなら、編集もその URL で行うか、後続のクラウド同期が必要。

### C. ディスプレイキャプチャ

全画面ブラウザ + 配信モード。他アプリが写るリスクあり。単一用途 PC 向け。

## OBS 側の推奨設定

| 項目 | 推奨 |
|------|------|
| キャンバス | 1920×1080 |
| FPS | 30 または 60（駒ドラッグの滑らかさは 60 が有利） |
| エンコーダ | 環境に応じて x264 / NVENC |
| ブラウザ HW 加速 | ON（Canvas が重い場合） |

## ZoneBoard 側の配信 Tips

- 駒ドラッグで **向きが追従**し、ドラッグ中は駒がわずかに拡大（配信映え）
- ロゴはピッチ上を **自由ドラッグ**（センターサークル配置可）
- 5レーンは配信でノイズなら OFF
- 駒サイズ: 解説の見やすさなら「戦術（大）」、配置の精密さなら「精密（小）」

## やらないこと（SPEC どおり）

- ボード内 Webcam（顔出しは OBS の映像ソースで合成）

# ZoneBoard × OBS 配信メモ

**更新:** 2026-08-23

## 推奨パス（3 手）

アプリの **設定 → OBSで使う** と同じ。

1. ブラウザウィンドウを **1920×1080** にする
2. ボードで **配信モード**（キー `B`、または `/board?broadcast=1`）
3. OBS → ソース → **ウィンドウキャプチャ** → このブラウザ。**クライアント領域 ON**

配信用 URL は設定の「OBSで使う」からコピーできる（例: `https://zoneboard.app/board?broadcast=1`）。同じウィンドウ・同じ localStorage。ブラウザソースは使わない。**配信中は設定を開かない**（モーダルがキャプチャに写る）。

OBS キャンバスも **1920×1080**、**60 fps** 推奨（駒ドラッグが滑らか）。

## 操作中のフォーカス（ウィンドウキャプチャ）

- **駒を動かすとき**は、キャプチャ中の **ブラウザウィンドウをクリック**してフォーカスを戻す
- **OBS のプレビューをクリック**するとフォーカスが OBS 側に移り、駒は動かない
- フォーカスが外れたとき、配信画面の上端に小さな **「クリックして操作」** が出る

## ホットキー（ZoneBoard ↔ OBS）

| ZoneBoard | 動作 |
|-----------|------|
| `B` | 配信モード ON / OFF |
| `Esc` | 配信解除 |
| `[` `]` | 局面切替 |

OBS で **B** や **Esc** を配信開始・停止などに割り当てている場合は、**OBS 側のショートカットを変える**（ZoneBoard のキーは変えない）。

## ボードの置き場所（アプリ側）

| モード | レイアウト | OBS 向け |
|--------|------------|----------|
| 編集 | 薄いヘッダ + キャンバス + 右ドロワー | キャプチャ範囲にドロワーが入りやすい |
| **配信モード**（`B`） | ドロワー強制クローズ。解除ボタンのみ端に残る | **推奨**。ピッチ面積 ≥80% 契約 |

推奨ウィンドウサイズ: **1920×1080**（16:9）。ピッチは FIFA 推奨 **105×68**（≈1.544:1）なので、上下にサブ帯・タイトル分の余白が乗る。

## OBS の取り方

### 推奨: ウィンドウキャプチャ

1. ZoneBoard を通常ウィンドウで開く（1920×1080 推奨）
2. 配信モード ON（`B`）
3. OBS → ソース → **ウィンドウキャプチャ** → ブラウザウィンドウを選択
4. 「クライアント領域」相当があれば ON（枠・タイトルバーを除外）

注意: 他タブや通知が写り込む。ブラウザ UI（タブバー）はウィンドウ次第で残る。

### 使わない: ブラウザソース

OBS の **ブラウザソース**（URL 直読み）は **別プロファイル**のため、通常 Chrome の localStorage と共有されない。この Chrome で編集した駒・局面は **写らない**。ZoneBoard の配信では **使わない**。

（技術メモ: 編集も OBS 内ブラウザで行うなら同期は取れるが、別タスク。）

### その他: ディスプレイキャプチャ

全画面ブラウザ + 配信モード。他アプリが写るリスクあり。単一用途 PC 向け。

## OBS 側の推奨設定

| 項目 | 推奨 |
|------|------|
| キャンバス | 1920×1080 |
| FPS | **60**（駒ドラッグの滑らかさ。30 も可） |
| エンコーダ | 環境に応じて x264 / NVENC |
| ブラウザ HW 加速 | ON（Canvas が重い場合） |

## ZoneBoard 側の配信 Tips

- 駒ドラッグで **向きが追従**し、ドラッグ中は駒がわずかに拡大（配信映え）
- ロゴはピッチ上を **自由ドラッグ**（センターサークル配置可）
- 5レーンは配信でノイズなら OFF
- 駒サイズ: 解説の見やすさなら「戦術（大）」、配置の精密さなら「精密（小）」。ズーム寄せでも画面上の駒はほぼ同じ大きさ（密度補正）。Match の Piece Size 値は変わらない

## やらないこと（SPEC どおり）

- ボード内 Webcam（顔出しは OBS の映像ソースで合成）
- チャットも OBS 側。ボードに載せない
- **広告**（運営・ユーザ設定とも。配信キャプチャ面に出さない。2026-08-24）

## 1. ユーザジョブ MECE（6 区画）

配信者が試合日にやる仕事を、重複なく・合せて尽くす。

| # | ジョブ | ユーザの一言 | ZoneBoard の正本面 | 摩擦ゼロの定義 |
|---|--------|--------------|-------------------|----------------|
| **J1 見せる** | 視聴者にピッチだけ届ける | 「OBS に芝だけ」 | 配信モード `B` / Esc | 1 キーで chrome が消え、16:9 契約が壊れない |
| **J2 動かす** | 配信中・準備中に駒と線をいじる | 「押したら動く」 | ツールレール · 選択プロパティ · Undo | 辞書なし。常時パネル肥大なし |
| **J3 切り替える** | 局面単位で物語を進める | 「CK に戻る」 | 局面チップ · `[` `]` · 複製 | 配置＋線＋画角が一塊で復元 |
| **J4 残す** | 次に言うこと・振り返りを書く | 「頭の外に出す」 | `scene.notes` | B / PNG に映らない。切替前に先読みできる |
| **J5 出す** | 告知・サムネ・ポスト用に静止画 | 「1枚欲しい」 | Settings · PNG プリセット | 配信を止めなくても／止めた直後に出せる |
| **J6 探す** | 前回のボードを再開する | 「昨夜の続き」 | ボード切替（浅い） | 深いフォルダを開かせない |

**意図的にジョブにしない（競合 Lineup / コーチアプリの席）:**

- App Store 買い切りのスタメンジェネレータ
- 運営 4-3-3 カタログ＋整列アニメ
- セッション PDF · 用具カタログ
- 別 URL の「OBS 専用スタメンサイト」

## 2. 試合日タイムライン（摩擦マップ）

ユーザ視点の時間軸。新 UI タブは増やさない。

```
[配信前 〜60分]  J6 探す → J2 名簿/XI → J2 並べる → (任意) J5 PNG 告知
[キックオフ前]   J1 B で見せる · コメント拾いながら J2 微調整 · J3 局面複製で案B
[インプレー]     主に映像。ボードはセットプレー待ち等で J3 切替（稀）
[ハーフ / 後]    J3 振り返り局面 · J4 notes · J5 PNG
```

| 時間帯 | やってよい摩擦 | やってはいけない摩擦 |
|--------|----------------|----------------------|
| 配信前 | 名簿貼り付け · XI チップ · ドラッグ | フォーメ一覧から選ばせる · ウィザード |
| 配信中 | B · `[` `]` · 複製 · ツールレール短ラベル | 設定モーダル · 深いドロワー · notes を芝に出す |
| 配信後 | PNG · notes | 別アプリへミラーリングし直す |

## 3. 区画別仕様（既存機能の契約言語）

### 3-1. J1 見せる

| 項目 | 仕様 |
|------|------|
| 入口 | `B` · 配信用 URL |
| 画面 | ピッチ最大化 · 配信 chrome は最小（局面 · ツール名 · 解除） |
| やらない | Webcam · チャット · 運営ロゴ強制 · notes 表示 |
| 成功 | 「あ、画面がきれいになった」（UI_UX 受け入れ） |

### 3-2. J2 動かす

| 項目 | 仕様 |
|------|------|
| 入口 | ツールレール · ホットキー · 選択時インスペクタ |
| 原則 | 選択されていない対象のプロパティは出さない（文脈 UI） |
| スタメン談義 | **名簿 → XI → 配置**。形はフリー。左右非対称・段差を妨げない |
| やらない | 運営フォーメボタン · 「Lineup Mode」という別モード名 |

### 3-3. J3 切り替える

| 項目 | 仕様 |
|------|------|
| 入口 | 局面チップ · `[` `]` · 配信中複製 |
| 単位 | 配置＋描画＋`viewport`（画角） |
| やらない | 局面ごとにピッチ物理（フル／ハーフ）を切り替えて OBS 比を壊す |

### 3-4. J4 残す

| 項目 | 仕様 |
|------|------|
| 入口 | Scenes の局面メモ |
| 表示 | 編集時のみ。B · PNG には出ない |
| やらない | ピッチ Text ツールとメモの統合（役割分離を維持） |

### 3-5. J5 出す

| 項目 | 仕様 |
|------|------|
| 入口 | 設定の PNG 書き出し |
| 用途 | 告知・サムネ・ポスト。**ライブ本線ではない** |
| プリセット | 正方形 / 16:9 / 4:5 / Story / ピッチ比（既存） |
| やらない | 比率ボタンに秘密ズームを結ぶ（COMPETITIVE_LP 決定） · 専用「スタメンジェネレータ」画面 |

**スタメン1枚の意味（再定義）:**  
「Lineup アプリの代替画面」ではなく、**いまのピッチ状態を SNS 枠で切った PNG**。名前表示 ON・試合帯の有無は既存トグルで足りる。

### 3-6. J6 探す

| 項目 | 仕様 |
|------|------|
| 入口 | ボード切替 · LP「続きから」 |
| 深さ | 最大3枚。コーチ用深い Home を真似しない |
| Later | Local Library Pro（ユーザ保存の配置・名簿）— **運営カタログではない** |

## 7. ブラッシュアップ意見（仕様に入れない提案 · 議論用）

衝突しない範囲の「より良く」だけ。採否は別決定。

### 7-1. 採りたい（低コスト · 方針一致）

1. **CMO 一文（フォーメ非所持の楔）** — **実装済（2026-09-06）:** LP `lpCanTitle`（ja/en + 全ロケール）  
   - **確定:** 「型ではなく、この試合のスタメン。」 / *Not a template — this match's XI.*  
   - **避ける:** 「並び」（内輪・抽象）· 「今夜の〜」だけ（PL / ブンデス等のデイゲームを切り捨てる）  
   - LP H1 の「今夜の OBS」は配信スロットの口語として残してよいが、**フォーメ楔のコピーでは試合単位に寄せる**
2. **J5 の呼び方:** UI に「スタメン画像」専用ボタンを作らず、Export 説明に「告知・サムネ用」を足す程度。  
3. **名前表示:** 試合前ジョブの既定推奨は hint のみ（新規ボード既定 OFF は維持可）。

### 7-2. 慎重（やりすぎると衝突）

4. **「ざっくり散開」ボタンの商品化** — 内部足場をユーザ向けに出すと「軽いフォーメ」に見える。出すなら **無名・1回限りのリセット** に限る。  
5. **配信用レイアウト（左 XI・右カメラ枠）** — OBS の仕事をボードに取り込む。PRODUCT_NOTE の境界（Webcam やらない）に抵触しやすい。  
6. **ワンクリック左右対称整列** — 非対称方針と矛盾。禁止寄り。

### 7-3. Later で価値が出る

7. **Library「並び」** — ユーザが保存した非対称配置の再利用（運営カタログではない）。  
8. **局面検索（label + notes）** — B-063。J4/J6 の深化。  
9. **局面取込（B-070）** — 試合後ジョブ。本仕様の J1–J6 と直交（別大型）。

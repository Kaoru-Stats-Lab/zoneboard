# 日本語 UI ボイス（ja 正本）

**読者:** 解説配信者（OBS / Canva 慣れ）> 部活・実況系 VTuber > 一般コーチ  
**参照:** [`UI_UX.md`](../../UI_UX.md) · chrome は配信ソフト語彙

## 文体

| 場所 | 文体 |
|------|------|
| LP · タグライン | 常体 · 短文 · 声に出して 15 秒以内 |
| ボタン · ツール名 | 名詞または 2–4 字動詞。ですます禁止 |
| hint · 設定説明 | 常体。1–2 文。括弧で補足可 |
| 確認ダイアログ | ですます可（「〜しますか？」） |
| Cookie · フッター注記 | 常体 · 平易。公文体禁止 |

## 語彙

| 使う | 避ける |
|------|--------|
| ピッチ · スタメン · 局面 · 配信モード | 芝 · 駒（将棋連想）· オブジェクト |
| UI · ウィンドウキャプチャ · OBS | ツールを消す（直訳）· 読み物ページ |
| パス · ラン · ドリブル | Pass/Run をカタカナだけで並べる説明 |
| アカウント不要 · 端末に保存 | 登録なし（LP では可）· ローカル保存（説明書） |
| ガイドなどの長文は英語版 | 読み物ページは英語です |

## カタカナ

- OBS · IG · Story · PNG · CK · PK · GK はそのまま
- ウォッチアロング → **試合配信** / **実況配信**
- ウィンドウキャプチャ → LP では **ウィンドウキャプチャ** OK · 短文では **OBS に映す**

## Short キー

- ~6 文字（CJK）目安 · レイアウト変更禁止
- 意味は `title` / hint に全文

## 禁止

- 他ロケールからの直訳調（es/de の Cool 軸コピペ）
- 過剰な敬語 · 「〜していただけます」
- FAQ / About ラベル（**Pending** — 別タスク）

## 2. 調べる粒度（サッカー PRODUCT_NOTE と同型）

各国・各言語圏について、次の表を埋める。

| # | 観点 | 聞きたいこと |
|---|------|--------------|
| A | **競技・指導の厚み** | クラブ数感、指導資格、FIFA/大陸連盟の教材の使われ方 |
| B | **戦術ボードの悩み** | 何で図を描いているか（ホワイトボード、紙、アプリ名）。不満（ピッチ比、線、保存、広告、配信） |
| C | **使われているツール** | TacticalPad / Coach Tactic Board / TACTICALista / ローカル製品。フットサル・ビーチ専用の有無 |
| D | **補助線・語彙** | 3廊下・プレス線・10m・黄9m・射線が現地語でどう呼ばれ、ボードに必須か |
| E | **配信者** | YouTube / Twitch / Kick 等で戦術図を出す人はいるか。スコアは OBS 別か。ピッチ全面需要 |
| F | **言語 UI** | es / pt-BR / pt-PT / it / fa / ru の優先度。v1 は ja/en のみで足りるか |
| G | **ZoneBoard が刺さる点** | 「正しい線がある Web」「登録不要」「ユーザロゴ」「配信モード」のどれが効きそうか |
| H | **やらない方がいいこと** | 現地で嫌われる UX（例: サッカー5レーン流用） |

**出力形式（Gemini に強制）:**

1. 国×競技のマトリクス表  
2. 言語圏サマリ（es / pt / it / ru / fa）  
3. ZoneBoard への含意（Must / Should / Later / やらない）  
4. 不確実な点・要一次情報（現地コーチに聞くべき問い）

## 結果メモ（2026-07-04）— ChatGPT / Claude / Gemini 統合

3ソースを突き合わせた**プロダクト判断用サマリ**。一次情報（現地コーチ）と矛盾したら一次を優先。

### 合意していること（実装・方針の裏付け）

| 項目 | 判断 |
|------|------|
| フットサル: 3廊下・プレス線・10m第2PK | **業界の共通言語。Must。** 実装済みで正しい方向 |
| ビーチ: 黄9m仮想線・射線 | **Must。** 実装済み。専用ボードが世界的に薄い＝楔 |
| サッカー5レーン／フットサル廊下のビーチ流用 | **やらない**（専門指導者から見放される） |
| 選手DB・スコア・タイマー | **やらない**（OBS／他ツール） |
| ビーチの配信者人口 | フットサルより**少ない**（通年コンテンツ不足・BSWW寡占）。ただし講習・解説収録・投影では配信モードが効く |
| 競合 | TacticalPad が多競技デファクト。重い・高い・配信用クリーンUI不足が隙 |
| AR / IR / RU | **登録不要・ローカル保存・無料**が決済・制裁環境で特に刺さる（推測強めだが3ソース一致） |

### 用語・表記（ローカライズ時）

| 言語 | フットサル例 | ビーチ例 | 注意 |
|------|--------------|----------|------|
| es | pasillos / carriles, línea de presión, segundo penalti | línea de 9 metros, pasillo de tiro | AR は *fútbol de salón* 表記の検討余地 |
| pt-BR | corredores, linha de pressão, segundo pênalti | **futebol de areia**, linha dos 9m | 最大市場 |
| pt-PT | corredores 等（近い） | **futebol de praia**（areia と違う） | BR 語彙の強制は嫌われる |
| it | — | linea dei 9 metri, corridoio di tiro | ビーチ Should |
| ru / fa | — | 現地語あり | Later。RTL(fa)は中途半端実装禁止 |

### ローカライズ優先（ja/en の次）

3ソースで **es 先 vs pt-BR 先が割れた。**

| ソース | 推奨1位 | 根拠の型 |
|--------|---------|----------|
| ChatGPT | **es** | 西語圏の広さ・戦術コンテンツ文化 |
| Claude | **pt-BR** | BR が両競技のリファレンス＋指導者ビジネスの厚み |
| Gemini | **es** | 広延性・Hilos Tácticos・TacticalPad牙城を避ける |

**ZoneBoard 採用判断（暫定）:**

1. **v1:** ja / en のまま出荷・利用データ（国・言語）を見る  
2. **v1.1 言語:** **es を先**（西・亜・中南米を一網。戦術スレッド文化とマイロゴが噛む）  
3. **直後:** **pt-BR**（フットサル＋ビーチ両方の最大単一国。表記は areia）  
4. **その後:** pt-PT（praia 分岐）、it、fa、ru  

pt-BR を先にする強い理由（Claude）も残るので、**アクセスログで BR が突出したら入れ替え可。**

### ロシア（ビーチ）

国際大会停止が続く。**商業優先度は低い。** 国内指導は続くため「無料・登録不要」は相性良いが、投資対効果は後回し。政治的表記に注意。

### 実装ギャップ（海外調査後も残るもの）

| 状態 | 項目 |
|------|------|
| **済** | 別競技ページ、寸法、5人、3廊下、プレス線、10m、黄9m、射線ON/OFF、砂色 |
| **Should（言語）** | es → pt-BR（上記順） |
| **Should（機能・FB後）** | フォーメプリセット、射線を近いゴール2本だけ、浮き球表現、GKパワープレー色 |
| **やらない** | レーン混同、クラウド強制、選手DB、スコア |

### 現地確認の優先問い（統合・短縮）

1. 3廊下は毎回ONがよいか  
2. プレス線の本数・呼称（1/4 vs 10m線）  
3. 射線は4本か自陣2本か／ポスト内側基準か  
4. TacticalPad の最大の不満は何か  
5. 配信用は透過PNG／OBSが主流か  
6. es 一括で AR の *fútbol de salón* は足りるか  
7. pt-BR / pt-PT の UI 分岐は必須か  
8. 出力形式の好み（PNG / PDF）  

詳細な国別表は ChatGPT / Claude / Gemini 各回答を参照（本リポには要約のみ保持）。

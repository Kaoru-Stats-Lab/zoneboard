## 1. 何が 16:9 か

| | 比率 | 備考 |
|--|------|------|
| **配信フレーム**（正本） | **16:9** | 窓内に contain。横リサイズしてもこの箱の中身の構図は同じ |
| **ピッチ面** | 競技コート比（サカ ≈1.54:1） | フレーム内で contain。歪めない |
| **編集モード** | 16:9 **なし** | 窓いっぱいに芝。配信契約の対象外 |

見てわかる印: 配信モードではフレームの外が **黒 matte**（`#0a0a0a`）。芝緑が窓いっぱいに広がっていたら **16:9 を守っていない／編集モード／未デプロイ**。

## 2. 配信モードの積み上げ

```
┌────────── 窓（任意アスペクト）──────────┐
│ matte（黒）                              │
│   ┌──── 16:9 フレーム ────┐             │
│   │ 黒帯（スコア／TL）      │  ← フレーム上端・フレーム幅 │
│   │ ピッチ＋芝ランオフ      │             │
│   └────────────────────────┘             │
│ matte                                    │
└──────────────────────────────────────────┘
```

1. `broadcastFrameRect(W,H)` → 最大 16:9 を中央  
2. 帯高は **フレーム高**基準（`matchBannerHeight(frame.w, frame.h)`）  
3. 帯は `translate(frame.x, frame.y)` してフレーム内に描く  
4. ピッチは `frame` の帯下に contain  
5. キャンバス地・フレーム外は `BROADCAST_MATTE`（芝緑にしない）

横に伸ばす → 左右の matte が増えるだけ。**16:9 島（帯＋ピッチ）は相似のまま**。

---

## 3. 編集モード

- 帯は窓上端・全幅  
- 16:9 なし。余白は芝ランオフ緑  
- ツールレールあり → 「選択／解除」が見える画面はだいたい編集

---

## 4. 色

| 領域 | 色 |
|------|-----|
| フレーム外 matte | `#0a0a0a` |
| 黒帯 | `#141414` |
| フレーム内ランオフ | `#1f5230`（芝時） |

緑はクロマキー色ではない。

---

## 5. 運用

推奨窓 **1920×1080**（フレーム＝窓）。`B` で配信モード。ウィンドウキャプチャ。

窓が 16:9 でないとき、帯は **フレームの上端**（窓の物理上端より下に matte が付くことがある）。16:9 を優先する。

---

## 6. 一文

> 配信の 16:9 は **黒い枠の内側**。帯もその中の一番上。外の黒が無い／緑だけなら、16:9 は守れていない。

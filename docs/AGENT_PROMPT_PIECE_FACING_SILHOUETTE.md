## 1. 目標シルエット（必須）

### 現状の問題

`drawPiece` が:

1. `arc` でキット色円＋白 stroke
2. 続けて **別 path** で白三角 fill（＋細い暗 stroke）

を描いている。三角底辺が円周の弦になり、**白縁と▶の継ぎ目にノッチ／段差**が出る。拡大時に「安い貼り付けマーカー」に見える。

### 正しい形

- **円＋短い一体ノーズ**の **1本の閉パス（シルエット）**
- 外枠の白は **そのパスに stroke を1回**（または同等の一体輪郭）。円と三角を別 fill して重ねない
- キット色の fill は **円本体**（番号の座）を優先。ノーズは白（または外枠と同色）で向きを示す。滴型・ピン型・全体をキット色の涙滴にしない
- 番号の光学中心は **円の中心のまま**（ノーズ側へずらさない）
- ノーズの長さ比は現行に近い **≈ 0.4–0.45 × r**。幅も現行三角と同程度。長くしない

### 幾何の要点

- 三角の底辺を「円周を切る弦」にしない
- ノーズは円周上の2点から接線付近で出て先端へ。**輪郭が連続**し、継ぎ目の黒い隙間や段差がないこと
- `lineJoin = "round"` 等で先端・付け根を滑らかに（ジャギーの主因が接合破綻であること）

## 2. 可変サイズ時の挙動（必須）

コマは大きくも小さくもできる。**形の比率は全サイズ共通。画面上の下限だけ床を置く。サイズで別シルエットに分岐しない。**

| 層 | 値 | 意味 |
|----|-----|------|
| `pieceScale` | 0.5–1.6（精密 0.65 / 標準 1 / 戦術 1.35） | ユーザ意図の大きさ |
| bench | `base * 0.48` | さらに小さい |
| `densityZoom` | ズームで画面上半径を抑える | CK 等。PRODUCT_NOTE 二層モデル |

### ルール

| 条件 | 挙動 |
|------|------|
| **小**（精密・ベンチ・寄った画角） | ノーズ長・幅に **画面 px 下限**（目安 tip 出っ張り ≥ 3–4 CSS px 相当）。小さいとき向きを消さない |
| **中** | 比率の基準帯。一体感が一番効く |
| **大**（1.35–1.6） | ノーズ比は伸ばさない。白縁は `clamp(比例, 下限, 上限)` で絶対 1.5px 固定のまま細く見えないようにする |
| **禁止** | `if (r < …) hide nose` · 大サイズだけ滴型 · `pieceScale` / locale で path 分岐 |

### 縁（stroke）

- 塗り半径を白縁が食い潰さない（**外側 stroke** または fill 半径を縁の半分だけ内側にする等）
- 選択時の二重縁（暗ハロー＋白）の一体感も、可能ならシルエット全体に沿わせる。難なら円本体＋ノーズ外枠が途切れないことを優先

### ヒット・選択

- **向きドラッグ**（`hitsPieceFacing`）: ノーズ外側ヒットを維持。見た目が小さくてもヒット余裕（既存 `pointerHitSlop`）は維持してよい。見た目の床とヒットの床は分けてよい
- **選択リング**（現行 ≈ `r * 1.72` の円）: 大サイズでノーズ先端がリングを突き破って「切れた」見た目にしない。先端クリア、または先端を包む。リングだけ古いまま先端切断は不可
- **利き足 L/R 小丸**: 位置ロジックは維持。向きノーズと混同しない（PRODUCT_NOTE）

## 4. 受け入れ条件

1. **見た目:** 標準サイズで、白外枠と向きが **一つの輪郭**に見える。接合ノッチがない（拡大スクショで確認）
2. **サイズ:** `pieceScale` を min / position / balanced / tactics / max で切り替え、向きが消えず・大でサメヒレ化しない
3. **ベンチ:** ベンチ駒でも向きノーズが一体で読める
4. **操作:** 向きドラッグ · `R` · 移動追従の facing が壊れていない
5. **選択:** 選択リングがノーズを無惨に切らない
6. **番号:** 円中心のまま読める（キット明暗の ink ロジックは既存 `pieceInk` のまま）
7. **回帰:** ghost / sentOff / 選択 / ドラッグ影が破綻していない
8. 型チェックまたは既存の軽い検証（プロジェクトに合わせて `npm run build` または該当 test）。i18n-chrome は文言未変更なら必須ではない

## 5. 実装ヒント（拘束ではないが推奨）

現行三角（参考）:

```ts
const rad = (piece.facing * Math.PI) / 180;
const fx = x + Math.cos(rad) * r;
const fy = y + Math.sin(rad) * r;
const tx = x + Math.cos(rad) * (r + r * 0.45);
const ty = y + Math.sin(rad) * (r + r * 0.45);
const ox = Math.cos(rad + Math.PI / 2) * r * 0.35;
const oy = Math.sin(rad + Math.PI / 2) * r * 0.35;
```

推奨アプローチ例:

1. 円弧（ノーズ付け根の角度 a0→a1）＋先端への2辺、を **単一 `beginPath` → fill（キット）→ 必要ならノーズ白を同じ外枠 path で clip/二次 fill**、または  
2. **外枠用の union path**（円＋ノーズ）を白 fill → 内側に少し小さいキット円、ノーズは白のまま残す  

どちらでもよい。**継ぎ目が見えないこと**が合格条件。

画面 px 床の目安（定数名は任せる）:

```ts
const tipLen = Math.max(r * 0.45, 3.5); // device/CSS px 相当。ctx 変換に注意
const tipHalf = Math.max(r * 0.35, 2.5);
```

`devicePixelRatio` や canvas の変換行列がある場合は、**画面上の見た目 px** になるよう換算すること。

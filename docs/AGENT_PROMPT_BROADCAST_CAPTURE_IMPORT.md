## 何を決めるか

ZoneBoard（ブラウザ戦術ボード · OBS 窓キャプチャ · 配信モード B · 登録なし · ローカル保存）で、**配信画像／動画から局面ドラフトを作る**機能（英: **Broadcast Capture Import** / 日: **局面取込**）を、次の大型アップデートの芯としてどう設計するか。

特に次を **1本の推奨**にまとめる:

1. **スコープ境界** — 静止画のみ / 動画フレーム選択まで / 連続トラッキングは不可、のどこまでを「大型 v1」にするか  
2. **動画前段** — [SUGUDASU 動画コマ抜き](https://sugudasu.com/video-frame) 相当エンジンを **リンク / 移植 / 埋め込み**のどれにするか（ブランド非掲出前提）  
3. **検出・座標化** — 何を自動で置き、何を手修正に残すか（駒だけ / 番号 / 線は出さない 等）  
4. **Go / No-Go 条件** — 精度・配信テンポ・非送信・学習コストのゲート

CPO · シニア UI/UX · ウォッチアロング配信者目線。根拠のない一般論は書かない。

## 調査すべき問い（すべてに答える）

### A. ユーザジョブ

1. **誰が**局面取込を Must とするか — ウォッチアロング配信者 / 事前解説（録画を見ながら準備） / コーチ教材 / その他。優先順位と頻度。  
2. **入力の実態** — OBS 録画 MP4 · ブラウザ録画 · YouTube ダウンロード · テレビキャプチャ · 他ボードの PNG · Sky 系 2D タッチパネル画像。どれが主か。  
3. **今の回避策** — ゼロから手置き · 局面複製 · 口頭のみ · 別アプリでスクショ。ボトルネックはどこか（時間 · 背番号不明 · 斜め映像）。  
4. **成功の定義** — 「この瞬間の XI 配置が 30 秒でボードに乗る」で足りるか。番号一致・線の自動生成は必要か。

### B. スコープ境界

5. **Phase A（静止画）** だけで大型として売れるか。動画 UI は Phase B でよいか。  
6. **やらないこと**を明確化 — 連続トラッキング · パス自動生成 · 選手同定 DB · 実写カメラ校正の本線化、等。  
7. **斜め実写 vs 俯瞰ボード画像** — 最初の対応入力はどちらか。homography / ピッチ検出の現実コスト。

### C. 動画前段（コマ抜きエンジン）

8. [video-frame](https://sugudasu.com/video-frame) の能力と限界（形式 · fps 誤差 · 大容量 · iOS）を要約。ZB ジョブに足りるか。  
9. **置き方 3案**を Pros/Cons/コスト/ブランドリスク/メンテで比較:

| 案 | 概要 |
|----|------|
| **L. リンク誘導** | 動画は外部コマ抜き → PNG を ZB にドロップ |
| **P. エンジン移植** | 同等ロジックを ZB 局面取込フロー内に内蔵（SUGUDASU ブランド非表示） |
| **E. 埋め込み** | iframe / deep-link 往復 |

10. **推奨の置き方を1つ**。条件付きなら条件を書く。

### D. 検出・座標化（PNG → scene）

11. 現実的な手法の比較（各短段落）— 古典 CV（円・色）· オンデバイス ML · クラウド Vision · 手動アンカー（4点キャリブ）+ クリック配置。  
12. **自動で置くもの / 手に残すもの**の推奨表（駒位置 · 背番号 · チーム色 · ボール · パス/ラン線 · viewport）。  
13. 失敗時 UX — プレビュー確定 · 部分取込 · 破棄。上書き禁止の原則を守れるか。

### E. 競合 · 隣接ツール

14. 戦術ボードで「画像／動画 → 配置」を持つ製品はあるか（TACTICALista · TacticalPad · TacticsBoard · Piero / Vizrt · Hudl · その他）。あるなら **誰向け・精度・価格**。  
15. SUGUDASU 単機能群との境界 — コマ抜きは前段、ZB は局面編集。混同リスク。

### F. リスク · ゲート

16. OBS 配信中に使うか、**配信前準備専用**か。配信中ならテンポ阻害要因。  
17. 著作権 · 実写配信キャプチャの利用（製品機能として書いてよいかの注意点。法律助言ではなくプロダクトリスク）。  
18. **Go 条件**（例: 俯瞰ボード画像で XI の ≥70% が ±1 マス相当に乗る、等）と **No-Go**。

### G. 決定

19. **推奨:** `Later 大型として採用（Phase を明記）` / `研究継続のみ` / `やらない` — **1つ**。  
20. **大型 v1（最初の出荷）のスコープ**を1段落。  
21. **成功指標 · UAT** を3–5個。  
22. **やらないこと**を5行以内。

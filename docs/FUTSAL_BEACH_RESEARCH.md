## 1. 市場・文脈（サッカーとの差）

### 1-1. フットサル

- **競技特性:** 5人制、40×20 級、ローリングサブ、累積ファウル→第2PK（10m・壁なし）、キックイン、オフサイドなし。
- **戦術語彙（デファクト）:** 3 Carriles / Pasillos（縦3廊下）、Línea de presión（プレス開始線）、ピヴォ／フィクソ／アラ、4-0 / 3-1 / 2-2 など。スペイン・南米教本が強い。
- **指導現場:** インドアコート、ホワイトボードが少ない会場が多い → **スマホ／タブレット戦術ボード需要**（Coach Tactic Board: Futsal 等のアプリが存在）。
- **配信:** スコア・タイマーは **OBS 別ソース**（KeepTheScore 等のフットサル用スコアボードが明示的に OBS 対応）。戦術図は画面共有 or 別ブラウザソース。
- **競合:** TACTICALista はフットサルコートあり（日本語圏で言及）。Tactical Board Online は多競技にフットサル・ビーチ含む。専用アプリは広告・クローン不可・MP4 約束不履行など **フロー破壊**の不満レビューあり。

### 1-2. ビーチサッカー

- **競技特性:** 5人制、約36×27、3ピリオド、砂、**ペナエリアはピッチに線がなく黄旗の仮想9m**、空中戦・Chilena（オーバーヘッド）が見せ場。GK もビルドアップに参加。
- **戦術語彙:** 1-2-2 / 1-3-1 等のフォーメ（FIFA Training Centre）、回転（futsal 的なポジション交換）、射線ブロック、保護された Chilena 動作。
- **指導現場:** FIFA Beach Soccer 公式教材はフォーメと回転の図解が中心。レーン分割は出てこない。
- **配信:** ワールドカップ級は映像が派手。個人配信者人口はフットサルより少ない想定。ハイライト解説・指導動画が主戦場になりやすい。
- **競合:** 正しい9m仮想線を持つ Web ボードは稀。TacticalPad 系アプリが近いが、配信最大化・ユーザロゴは ZoneBoard の差別化余地。

## 2. ペルソナ（サッカー P1 / P1b / P2 に対応）

| ID | 誰 | 今日の痛み（仮説） | ZoneBoard が担う | OBS / 他が担う |
|----|-----|-------------------|------------------|----------------|
| **F1** | フットサル解説・YouTuber | 協会ピッチのまま5レーンで説明してしまい違和感。狭いコート比が崩れる | 正しい40×20、3廊下・プレス線、10m点、配信モード | スコア・累積ファウル表示・タイマー |
| **F1b** | フットサル部活・クラブ監督 | インドアにホワイトボードがない。交代が多く紙が追いつかない | 5人＋ベンチ、局面切替、タブレットで駒移動 | 出場時間管理・スタッツ（別ツール） |
| **F2** | フットサル講習・ライセンス講習 | 3廊下とプレスラインを毎回手描き | オーバーレイ既定 ON | 配布資料 PDF（Export） |
| **B1** | ビーチ解説・ハイライト系 | ペナが「どこまで手使えるか」が図で伝わらない | 黄点線9m＋旗、射線 ON/OFF | スコア・ピリオド |
| **B2** | ビーチ指導者（国内は少数精鋭） | 回転と射線ブロックを砂場で口頭説明しづらい | 射線ガイド、5人配置、局面 | 動画解析・AI（非スコープ） |

サッカーの P1b（VTuber）はフットサル／ビーチでも成立しうるが、**第一ターゲットは F1 / F1b / B1**。人口はサッカーより小さいが、**正しい線があるだけで刺さる**ニッチ。

## 3. 戦術ボードで「何に悩んでいるか」

### 3-1. 共通（サッカー調査と同型）

| 痛み | 詳細 |
|------|------|
| **ピッチ比が違う** | 協会ピッチやバスケ用ボードで代用 → 距離感が狂う |
| **保存・複製** | ドリルのクローン／微修正ができないアプリへの不満（Futsal 専用アプリのレビュー） |
| **広告・課金壁** | 指導中・配信準備中のフロー破壊 |
| **配信でピッチが小さい** | ツールバー厚・運営ロゴ（ZoneBoard の既存楔） |
| **登録・同期の重さ** | 部活監督は「今すぐ開きたい」 |

### 3-2. フットサル固有

| 痛み | ボードへの含意 |
|------|----------------|
| 5レーンを載せると教本と矛盾 | **縦3廊下のみ**（実装済トグル） |
| プレス開始位置の共有が口頭だと曖昧 | **1/4・ハーフ線**（実装済） |
| 終盤のファウルコントロール説明 | **10m第2PK点は常時**（実装済）。累積ファウル**数**の UI は別（スコア側） |
| ローリングサブでベンチが動く | ベンチ人数多め・局面複製が効く。出場分管理はボードの仕事ではない |
| 4-0 等のセット | フォーメプリセット追加は Later（現状 1-2-1 系5人） |

### 3-3. ビーチ固有

| 痛み | ボードへの含意 |
|------|----------------|
| ペナが「見えない線」 | **黄点線9m＋旗**（実装済・常時） |
| レーンで空間を切ると嘘になる | **レーン類なし** |
| 守備は射線ブロックが本体 | **射線ガイド ON/OFF**（実装済） |
| Chilena・浮き球の軌道 | 自由曲線ラン／パスで足りる。専用アニメは不要 |
| フォーメ 1-2-2 等 | プリセット追加は FB 後（現状汎用5人） |

## 6. 仮説（FB で検証したい問い）

オーナーが疎い前提で、最初に聞きたいことだけ。

### フットサル

1. 3廊下＋プレス線の既定 ON は邪魔か、必須か  
2. 第2PK点の視認性は足りるか  
3. 欲しい初期フォーメは何か（4-0 / 3-1 / 2-2 …）  
4. 配信でスコア以外にボードへ載せたいものはあるか（載せない方針の確認）

### ビーチ

1. 黄点線の太さ・色は現場の旗イメージに近いか  
2. 射線は4本（両ゴール）でよいか、自陣ゴール2本だけがよいか  
3. 砂色ピッチは配信で眩しくないか／白の方がよいか  
4. 1-2-2 等のプリセット需要はどの程度か  

**FB の取り方（案）:** インドア／ビーチ指導者に URL を渡し、「協会ピッチで説明してたときと比べて」だけ聞く。機能要望リストは後回し。

## 8. グリッド／補助線 — 直すか？（MECE）

### 8-1. 日本語 UI だから日本独自概念に合わせるべきか

**結論: 幾何は FIFA/JFA 準拠のまま。日本語は「日本の指導現場の呼び方」に合わせる。グリッドの形自体を日本専用に作り直す必要は薄い。**

根拠:

- 国内教材（futsal.tech、フットサルバイブル等）は **スペイン由来の概念を日本語化**している（レーン／廊下、プレスライン、第2PK、エントレリネアス）。海外調査の 3 Pasillos / línea de presión と**同じ骨格**。
- プレスの目印として日本でも **ハーフウェーライン・第2PKライン**が明示される（＝我々の 1/4＝10m とハーフは現場語彙と一致）。
- ビーチは JFA 規則どおり **ゴールラインから 9m の仮想線＋黄旗**（独自概念ではない）。

つまり ja 優先＝**ラベルと既定 ON/OFF を日本の言い回しに寄せる**のであって、es/pt 圏と別の線を引く話ではない。

### 8-2. 修正候補 MECE

| 大分類 | 小分類 | 現状 | 直す？ | メモ |
|--------|--------|------|--------|------|

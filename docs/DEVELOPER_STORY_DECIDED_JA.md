# 決定稿（JA · note 第2稿）

**タイトル:** ワールドカップ配信で見た「Googleスライドで戦術解説」が、私のスイッチを押した

**更新:** 2026-08-30 · Claude 評価反映（事実修正 · 場面厚め · リード予告）

---

2026年、北中米ワールドカップの配信で、あるサッカー記者が画面共有の Google スライドで戦術を説明しているのを見た。図形をひとつずつ動かしながら、知識と熱量を注いでいる。それでも私の頭をよぎったのは、ひとことだけだった——**これは、アカン**、と。本文は、その瞬間に至るまでの話。

---

## 1. プレイヤー経験はない。けれど、私の半生にはいつもサッカーがあった

私自身は、サッカー未経験だ。ピッチの上で正式にボールを蹴ったことは一度もない。少年時代に近所の公園でボールを蹴った記憶すら、ほとんど残っていない。けれど、忘れられないサッカーの情景だけは、いつもどこかにあった。画面の向こう、スタンド、旅先——。

テレビの前で息をのんだ「ドーハの悲劇」。同じ頃、Jリーグ開幕戦で胸が高鳴った。加茂監督解任のニュースが走った年、韓国戦で山口素弘のループシュートに釘付けになった夜。出来事は年代を追うたびに、私のサッカー観を厚くしていった。未経験の私にとって、サッカーは「観るもの」であり、「感じるもの」。言葉と映像と熱気で、少しずつ輪郭が見えてくる過程そのものが、青春だった。

フジテレビの放送にしがみついて、中田英寿と中村俊輔のセリエAを追った。青嶋達也アナの実況に胸を躍らせ、風間八宏さんの解説で初めて「戦術」という言葉を知った。遠い世界の話のはずが、風間さんの言葉を通じて、少しずつ身近になっていった。『すぽると！』のマンデーフットボールで流れていた Hans Dulfer の Mickey Mouth やテーマ曲を iPod に詰め込み、擦り切れるほど聴いた。当時は「ヘビロテ」なんて言葉すらなかった。あの曲が流れるたび、試合の高揚が体の中で蘇る。

ミランでカカが輝き、リヨンでジュニーニョが黄金期を築いていた。スターとして世間の注目を浴びるカカとは対照的に、どこか不遇の天才として語られるジュニーニョ——そのフリーキックだけは、私を釘付けにした。蹴ったことはないのに、あの弧だけは体の奥まで沁みる。壁を越え、キーパーの指先を掠めて吸い込まれる軌跡。未経験の私でも、あれだけは「美しい」と直感できた。

日韓ワールドカップは、ただただ盛り上がった。日本全体が熱狂した——私にとって初めて、全身で感じる体験だった。鈴木隆行のベルギー戦でのつま先ゴール。稲本潤一の連携ゴールと、ふてぶてしいゴールパフォーマンス。街を歩いても、電車に乗っても、どこかでサッカーの話が聞こえる。未経験の私でさえ、「日本が戦っている」だけで胸が高鳴った。

大晦日の夜、夜行バスに乗り込み、元旦の国立競技場で天皇杯決勝を観るのが恒例になった。寒さの中、眠気を堪えながら揺られ、明け方の新宿に着く。国立のスタンドに足を踏み入れた瞬間、空気が変わる。

一番心に刻まれているのは、2003年1月1日、第82回天皇杯決勝——京都パープルサンガ対鹿島アントラーズ。0対1で迎えた後半開始から5分、**パク・ジソン（朴智星）** のヘディング同点ゴール。チームは逆転し、2対1でクラブ史上初のタイトル。間もなく PSV へ旅立つ彼の、日本での最後の大舞台。

試合後、見ず知らずの京都サポーターの渦に混じった。「オランダに行っても応援してるぞ！」——知らない人たちと、声が枯れるまで叫んだ。元旦の冷たい空気の中、喉が痛いのに止まらない。未経験の私にとって、それが「サッカーを生きる」一端だった。

もうひとつ、忘れられない夜がある。「イスタンブールの奇跡」。2005年5月25日、CL 決勝、リヴァプール対 AC ミラン。リアルタイムで観ていた。前半、ミランがマルディーニとクレスポの2ゴールで3点リード。この時点では、もう寝ようかと思ったほど。

後半、ジェラードのヘディングで様子が変わる。点を決め、ゴールからボールを持ち、チームメイトと観客を煽る。スタンドが波のように揺れ、テレビの前の私まで引きずり込まれる。「まだ諦めていない、いける」——闘志むき出しの姿に、完全に飲み込まれた。終わってみればリヴァプール優勝。身体中に疼くようなエネルギーが、しばらく止まらなかった。

## 2. 帰宅は24時過ぎ。それでも、暮らしのすぐ側にフットボールがあった

社会人になってから、毎日の帰宅は24時過ぎ。リアルタイム観戦から足が遠のいていった。ネットでいつでも試合が観られる時代ではない。録画すらままならず、結果を翌朝の新聞で知る日も増えた。

そんな私の救いが、雑誌『Number』だった。金子達仁さんの尖った記事を、二宮清純さんの辛口な批評を、多忙な日々の隙間で貪るように読んだ。ページをめくるたび、スタジアムの熱気が蘇る。あの頃買った『Number』は、今もダンボールの中に大切にしまってある。

それでも、生活のすぐ側にフットボールはあった。休みの日は三ツ沢、神戸、国立へ。スタンドで声を出し、隣の人と喜びを分かち、敗戦の後に沈む。代表戦の日、会社の何人かは日本代表ユニフォームで出社する。「あー、今日代表戦か、スタメンは誰だ？」——風通しのよい職場だった。

残業後21時、同僚とフットサル場へ。終電ギリギリまでボールを追う。元都道府県選抜や元ユースがゴロゴロいるのに、未経験の私も夢中で汗を流した。上手く蹴れなくても、追いかける楽しさだけは確か。息が上がり、足が重くなり、それでも「もう1試合」。

旅先でも、サッカーは置いてはくれなかった。フランスで出会った人と「リヨンが好き、ジュニーニョは最高のフリーキッカー」と言い合い、知らない国の知らない人と、スタジアムに近い高ぶりを分かち合った。

タイでは、プレミアリーグのラッピングが施された **MRT** に衝撃を受けた。車体に選手の姿が描かれ、日常の移動がそのままサッカーの気配をまとっていた。僧侶に「私はチェルシーファンだけど、あなたは？」と聞かれたこともある。プレミアリーグを観る僧侶——その意外さが、サッカーの普遍性を感じさせた。シンガポールでは、マレーシア・ジョホールの砂煙の中をスタンドまで足を運び、あの日の日本代表に思いを馳せた。

2006年ドイツW杯。ジーコジャパンは「史上最強」と呼ばれ、ブラジル戦のジュニーニョの無回転ミドルで川口能活からゴールを奪われた。4-1。試合後、中田英寿が天を仰ぎピッチに体を投げ出す。高揚の後の落胆。熱狂の後の静けさ。この忙しい十年にも、サッカーの熱気は、いつも側にあった。

## 3. ザックジャパンの衝撃、そして暗闇を照らした2011年

埼玉スタジアム、2010年10月。相手はメッシを擁するアルゼンチン。まさかの1-0。「ここから新しい日本サッカーが始まる」——胸が躍った。あの日スタジアムに集まったファンの多くの目的は「生のメッシ」だっただろうけど、それでも、空気は変わっていた。

翌2011年。日本にとっても、私にとっても、過酷な年。体調がすぐれない時期を過ごしていた。3.11。記憶は曖昧だ。世の中が深い悲しみと不安に包まれ、日常が音を立てて崩れていく感覚。私はただ、静かに過ごしていた。

暗闇の中で、私を支えてくれたのもサッカーだった。

震災のあと、ドイツで、ノイアーに促されてシャルケのユニフォームの下から日本へのメッセージを掲げた内田篤人。遠く離れたピッチで、自国を想う姿。画面越しに見たとき、胸の奥が熱くなった。言葉はいらなかった。ユニフォームを広げた、その一枚が、当時の私には十分すぎるメッセージだった。[^1]

[^1]: 写真クレジット: IMAGO / AFLO（内田篤人 · シャルケ04 · 2011）

同じ夏、「なでしこジャパン」が世界を制した。ギリギリのゲームを勝ち抜き、毎試合違うヒロインが生まれる。近賀ゆかりのスタミナ、大野忍の守備、川澄奈穂美のプレー、丸山桂里奈のゴール、澤穂希のキャプテンシー、海堀あゆみのスーパーセーブ——。もちろん、私も勇気づけられた一人。

優勝記念ユニフォームを買った。胸のワールドカップ優勝ワッペン。小さな布片が、2011年の夏を体に留めてくれている。暗い時期に、サッカーが差し込んだ光。2011年に、そう確信した。

## 4. 「Googleスライド」事件と、変な使命感

2011年から十五年。仕事も家庭もあり、サッカーは生活の横にいた。見方は静かに変わっていった。アジア予選突破は当たり前。私が画面の前に座るのは、ワールドカップと海外サッカーだけ。キリンカップも、アジア予選も、見なくなった。

2022年カタールW杯以降——キャプテン遠藤航の「優勝を目指す」に、しびれた。グループ突破が当たり前の世代にとっても、本気の宣言に聞こえた。

同時に、冷静に見ればこうも思う。優勝国は限られている。日本にプロリーグができてから、まだ三十年。歴史の厚みが違う。JFA に強豪国のような予算はない。硬直した協会——そう感じることもある。宮本恒靖会長には、期待半分、疑念半分。2004年アジア杯、キャプテン宮本のあの抗議の姿を知っているファンは、忘れないだろう。個人を攻撃するつもりはない。組織としての課題を、冷静に見ているだけだ。

YouTube や配信で試合を語る文化は、以前とは比べ物にならない規模に。私は Web プロダクトを作る側にもなっていた。最初は冷めたビジネス視点だった。「サッカーは世界一普及している。市場がこれだけ広ければ、儲かるんじゃないか」。下心と野心——それが最初の原動力だったかもしれない。

**2026年、北中米ワールドカップの季節。** その考えを一変させる出来事が起きた。

W杯 の熱気が高まる中、配信で戦術分析をしている記者を見かけた。知識も熱もある。画面共有で必死に動かしているのは、**Google スライド**。四角と丸を、ひとつずつ、ちまちまと。カーソルが追いつかない。説明のテンポが、ツールに引きずられる。視聴者側にも、その「もどかしさ」が伝わってくる。伝える側の熱量が、インターフェースに削がれている——画面越しにはっきりわかった。

「……これは、アカン」

風間さんの言葉で戦術を知り、金子さんの記事とスタジアムの熱気に支えられ、2011年のなでしこに勇気をもらった。そんな記憶があるのに、2026年になっても、プロがこんな道具で苦労している。熱量がツールに殺され、観る側のワクワクが削がれる。このままでは、サッカーに関わる人口そのものが減るんじゃないか——。

その瞬間、私の中で「変な使命感」が爆発した。ビジネスの視点は吹き飛んだ。残ったのは、「何かできるはずだ」という、根拠のない、しかし強い衝動。

## 5. 未経験の私だからこそ、できること

「サッカー未経験で、戦術の専門家でもない自分に、一体何ができるんだ？」

ピッチに立つことも、マイクを握ることもできない。風間八宏さんや戸田和幸さん、林陵平さんのように戦術を言葉で解くことも、金子さんのように鋭い文章で切り取ることもできない。けれど、あの記者のように「サッカーの魅力を熱く語る人たち」が、数秒で綺麗な画面を作れる環境を渡すことはできる。

一足飛びに強豪国へ追いつくわけではない。JFA の組織改革も、代表強化も、A級ライセンス取得の閉鎖性も、私一人ではどうにもならない。ピッチの上で伝説を残すことも、解説席で名言を残すこともできない。だから、**自分のコントロールの及ぶところ**に目を向けた。

ZoneBoard で戦術を語る基盤を作った。誰かに渡せる。JFA やメディアがすぐには届かない場所で、伝える側の熱量を削がないツールを渡す——それが、未経験の私にできる貢献だと感じた。

*（画像: ZoneBoard の画面）*

「日本がいつか男子 W杯 で頂点を掲げるために、未経験の私が裏方としてできること。それは、誰もがサッカーを直感的に、ストレスなく語れる世界を作ることだ」

2011年、暗闇の中で勇気をもらったように。深夜フットサルの高揚、スタジアムの熱狂、元旦の夜行バス、ジュニーニョのフリーキック、なでしこのワッペン——受け取ったものを、今度は裏側から支えたい。

2026年。北中米 W杯 の出来事をきっかけに、誰でも開けて、学習コストゼロで、ボタン一発で配信向けの綺麗な画面になるツールを作った。そうして生まれたのが、ZoneBoard です。

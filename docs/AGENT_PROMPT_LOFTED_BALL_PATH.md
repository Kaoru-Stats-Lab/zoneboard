## 調査すべき問い（すべてに答える）

### A. ユーザジョブ

1. **誰が**山なり軌道を欲しいか — 配信ウォッチアロング / コーチ教材 / セットプレー解説 / その他。優先順位。
2. **どの場面**で必須か — CK クロス · サイドからの浮き球 · ロングボール · シュート。頻度と「声だけで足りる」境界。
3. **今の回避策** — パスを手で曲線 · ペン · 局面複製 · 口頭。不十分なのはどこか。

### B. 業界の図式（2D 戦術板）

4. **欧米コーチング図** — パス = 破線 · ラン = 実線 等の記号。浮き球・クロスに **別記号**があるか。
5. **放送グラフィック / 解説番組** — 2D オーバーレイで山なり・放物線を使うか。使うなら **静止画**か **アニメ**か。
6. **日本語圏** — J リーグ解説 · ウォッチアロング · 戦術 note / X 図解。山なりの有無（スクショ・例があれば URL）。
7. **主要競合**（各1段落）— TacticsBoard · tactical-board · TACTICALista · The Tactics App · 他。path / curve / loft の有無と **誰向け**か。

### C. プロダクト設計（ZB 向け案の評価）

以下 **4案** をそれぞれ **Pros / Cons / 実装コスト（S/M/L）/ OBS キャプチャでの読みやすさ** で評価せよ。

| 案 | 概要 |
|----|------|
| **0. 現状維持** | パス破線のみ。山は手曲線 |
| **1. Pass 修飾** | 2点間を単一アーチにスナップ（Shift 等）。新ツールなし |
| **2. 線種追加** | `loft` / `cross` / B-059 `shot` 等。見た目を分離 |
| **3. 競合追随** | path アニメ · グレー開始点 · 曲線軌道パネル |

**ツールレール**は言葉のまま（パス / ラン …）。**icon グリッド化は非目標**。

### D. 視認性（芝生ピッチ）

8. 山なり破線 vs 直線破線 vs 実線アーチ — **緑芝 `#1a5c2e` 上**で Pass / Run / リンクと **混同しない**最小差は何か（色 · 太さ · dash · 単一アーチ）。
9. **配信解像度**（720p · 1080p ウィンドウキャプチャ）で、細い放物線は潰れるか。

### E. 決定

10. **推奨:** `v1 やらない` / `Later（条件付き）` / `v1 で最小実装（案番号）` — **1つ**。条件を明記。
11. **成功指標** — 採用した場合の UAT（例: 「CK 局面でクロス軌道が30秒以内に引ける」）。
12. **やらないこと** — スコープ外を3行。
